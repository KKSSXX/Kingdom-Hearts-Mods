# 1st Byte
| Byte | Gamepad | Keyboard |
| --- | --- | --- |
| 0x01 | Select | 3 or N |
| 0x02 | L3 Button | NONE |
| 0x04 | R3 Button | Right ALT // Mousewheel |
| 0x08 | Start | 4 or M |
| 0x10 | DPAD UP | UP / Mouseweehl UP |
| 0x20 | DPAD RIGHT | Right / EXT1 |
| 0x40 | DPAD DOWN | DOWN / Mouseweehl DOWN |
| 0x80 | DPAD LEFT | Left / EXT2 |

# 2nd Byte
| Byte | Gamepad | Keyboard |
| --- | --- | --- |
| 0x01 | L2 Button | C|
| 0x02 | R2 Button | C or E |
| 0x04 | L1 Button | Left Shift |
| 0x08 | R1 Button | R |
| 0x10 | △ | F / Right CTRL |
| 0x20 | ◯ | Space / Backspace |
| 0x40 | ✕ | Enter / Left Click |
| 0x80 | ▢ | Right Shift / Right Click |

# 3rd Byte
| Byte | Gamepad | Keyboard |
| --- | --- | --- |
| 0x10 | Right Stick UP | Mouse UP |
| 0x20 | Right Stick RIGHT | Mouse RIGHT |
| 0x40 | Right Stick DOWN | Mouse DOWN |
| 0x80 | Right Stick LEFT | Mouse LEFT |

# 4th Byte
| Byte | Gamepad | Keyboard |
| --- | --- | --- |
| 0x10 | Left Stick UP | W |
| 0x20 | Left Stick RIGHT | D |
| 0x40 | Left Stick DOWN | S |
| 0x80 | Left Stick LEFT | A |

If you change the button layout in the game settings, the Binary Flags remain exactly the same.
